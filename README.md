# Unemployment Analysis in India using Python

## Project Overview

This project analyzes unemployment trends in India using Python.

## Objectives

* Clean and preprocess unemployment data
* Analyze unemployment trends
* Study the impact of COVID-19
* Identify seasonal patterns
* Generate policy recommendations

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Visualizations

1. India Unemployment Trend
2. COVID-19 Impact Analysis
3. Top 10 States with Highest Unemployment
4. Seasonal Pattern Analysis
5. Labour Participation vs Unemployment
6. Correlation Matrix

## Key Findings

* Unemployment increased significantly during COVID-19.
* Tripura and Haryana recorded high unemployment rates.
* Seasonal spikes were observed during lockdown periods.
* Employment levels show a negative correlation with unemployment.
